## 一、是什么

**一条定义句，在第 62 课**（`L62:13-14`；该块的后半句是**线段**的定义，不是笔的）：

> 「两个相邻邻的顶和底之间构成成一笔，所谓笔，就是顶和底之间间的其他波动，都都可以忽略不算，但但注意，一定是相相邻的顶和底，隔隔了几个就不↵是了。而所谓谓的线段，就是至少少由三笔组成。但但这里有一个细微微的地方要分清楚楚，因为结合律是必必须遵守的。」

⇒ 拆开看，笔的定义由三句组成：**①** 两个**相邻**的顶和底之间构成一笔；**②** 中间的其他波动**都可忽略不算**；**③** 但**必须是相邻的**顶和底，隔几个就不算。

### ★ 原文给的划笔**程序**：三步骤（2026-10-02 补）

上面四步是**条件**；下面这段是原文给的**程序**。★ 本文件原先没有这一段。

**三步骤原文**（`L77:54-60`）：

> 「从上面笔划分的唯一性证明中，其实也知道如何去划分笔的步骤：↵一、确定所有符合标准的分型。↵二、如果前后两分型是同一性质的：↵①对於顶，前面的低於后面的，只保留后面的，前面那个可以 X 掉；↵②对於底，前面的高於后面的，只保留后面的，前面那个可以 X 掉；↵不满足上面情况的，例如相等的，都可以先保留。↵三、经过步骤二的处理后，余下的分型，如果相邻的是顶和底，那么这就可以划为一笔。」

★ **与上面四步的对应**：步骤一＝第 2 步『找相邻的顶分型、底分型』；步骤二＝**同类分型怎么取舍**（本文件原先没有这一条，是缺口）；步骤三＝第 3 步『定方向』。

★ **步骤二分两半，别只读前半**：`L77:56`-`:58` 是『**更极端的那个替换前一个**』（顶：前面的**低**于后面的 ⇒ 只保留后面的；底：前面的**高**于后面的 ⇒ 只保留后面的 —— **方向别写反**）；`L77:59` 反过来 —— **不够极端或相等的，一个都不删**。

**那『先都保留』下来的一串同类分型，成笔时用哪一个**（`L77:61-64`）：

> 「如果相邻的性质一样，那么必然有前顶不低於后顶，前底不高於后底：↵在连续的顶后，必须会出现新的底，把这连续的顶中最先一个，和这新出现的底连在一起，就是新的一笔，而中间的那些顶，都 X 掉；↵在连续的底后，必须会出现新的顶，把这连续的底中最先一个，和这新出现的顶连在一起，就是新的一笔，而中间的那些底，都 X 掉。↵显然，经过上面的三个步骤，所有的笔都可以唯一地划分出来。」

⇒ **用最先一个** —— 原文说的是把那串连续顶里**最先一个**和新出现的底连起来，中间那些顶都 X 掉。程序 `core/pen.py:106-108` 与之同向：新分型不比已记下的更极端时（`not beyond`），**保留先到的**那一个。
