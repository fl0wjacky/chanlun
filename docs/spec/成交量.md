## 一、是什么

★ **这个概念的难点不在定义，在作者对它的态度：两句话离得很远，必须一起读。**

- **理论层**（`L30:5`）：作者的理论出发点是**除了价格，一无所有**——成交量只是这条立场下的一个**括号注**，被化约成价格 × 数量 × 最小时间段，不是独立原量。**理论的定义链用不到它。**
- **看盘层**（`L9:21-22`）：作者把成交量和均线**并列**，说**一个带均线和成交量的 K 线图，比任何技术指标都有意义**。**看盘时，它是作者口中『最有用的那张图』的一部分。**

> 「交易中，你唯一需要明确的，就是无论市场价格是否完全反映信息，你都必须以市场的价格交易，而你的交易将构成市场的价格，对於交易↵来说，除了价格，一无所有(缠中说禅注：成交量可以看成是在一个最低的时间段内按该价格重复成交了成交数量个交易单位)。」

> 「①首先，技术指标，都单纯涉及价量的输入而来，都不是独立的，只需要选择任意一个技术指标构成一个买卖程序就可以。对于水平高点的↵人来说，一个带均线和成交量的 K 线图，比任何技术指标都有意义。」

⇒ 两句离得很远（`L9` 在讲『三个独立程序组』，`L30` 在讲交易的出发点），**必须一起读**：**理论的定义链用不到它，但作者看盘时把它当最有用的那张图的一部分**。所以『配角』这个词不准——准确说是『定义里缺席、看盘时在场』。全书唯一接近『定义』的仍是 `L30:5` 这个括号注，而且它把成交量化约掉了，**没有给成交量一个独立于价格的定义**。

- **作者两次说『成交量以后会说到』，但 108 课里再没展开**（预告未兑现，同 README 第四节 #12『能量动力结构的几何化』一个形状）：

> 「缠中说禅：成交量和走势一样，有着类型的分析，以后会说到。」

> 「缠中说禅：成交量以后会说到，均线参数都要自己去调试，有些人心急的，就要快点，每个人不同。」

⇒ 作者许诺过的『成交量的类型分析』**原文没给**。全书里成交量的每次出场，都是**辅助判断 / 选股经验 / 缺口定义的一个部件**，没有一次是把它当成理论的独立一维来讲。

## 三、特殊情况

- **放量骗线**：缠绕前的成交量不能放得过大，量突然放大又萎缩过快，骗线几率大增、缠绕时间拉长（`L12:28-29`）：

> 「3、第三，缠绕出现前的成交量不能放得过大，一旦过大，骗线出现的几率就会大大增加，如果量突然放太大而又萎缩过快，一般即使没有↵骗线，缠绕的时间也会增加，而且成交量也会现两次收缩的情况。」

- **放巨量＝顶部/出货信号**：背驰或放巨量要走人（`L7:45`）；巨量大阴线构造顶部，别在下跌反抽中介入（`L9:161`）：

> 「②另一种是第一波就火爆上涨，调整后第二波的上涨，一旦出现背驰或放巨量的，一定要小心，找机会走人。」

> 「首先请一定要记住，不要在以巨量大阴线构造顶部的下跌反抽中介入，这是投资的大忌。你的青海明胶大概就是这样买的。等吧，中线应」

- **庄股：成交次数决定中枢级别**——每天只成交一次、价位不变，只形成一分钟中枢、大级别中枢不能形成（`L20:20-21`，已收在 `中枢.md` §一）：

> 「B、成交次数与成交价位与中枢延伸的关系：↵还有一种特殊的情况，就是所谓的庄股，如果有一个庄家特别有毛病，每天就成交一次，每天的价位都一样，这样也只形成一个一分钟」

- **小级别的大幅突破：成交量是把它和一般中枢波动分开的信号**——这种突破伴随最猛烈快速的走势，成交量及力度都要相应配合（`L54:125-126`）：

> 「但这里有一个基本的前提：这种小级别的大幅突破必须和一般的中枢波动分开，这种情况一般伴随最猛烈快速的走势，成交量以及力度等↵都要相应配合。」

- **多路资金混战的股，用成交量做短线节奏**：萎缩下来买、急剧放大走（`L22:135`）：

> 「这种 N 个人在里面混战的，对於散户是最好操作的，成交量萎缩下来就可以找短线买点介入，成交量一急剧放大就找位置走人。因为成交」

- **缺口＝没有成交的区间**，缺口回补＝该区间重新出现成交（`L77:9-11`，归动力学组『缺口』，详见 `inventory_动力学.md` §11）：

> 「何谓缺口，就是在该单位 K 线图上两相邻的 K 线间出现没有成交的区间。例如，在上海指数日线单位的 K 线图里，1994 年的 7 月 29 日与↵8 月 1 日，就出现[339,377]这个区间没有成交。那就说，[339,377]是一缺口。↵而缺口回补的定义，就是在缺口出现后，该缺口区间最终全部再次出现成交的过程。这个缺口回补的过程，可能在下一 K 线就出现，也可能」

## 四、跟谁有关系

- **被当辅助（最重要的一条）**：**背驰**的辅助判断之一，和 MACD 并列（`L56:101`）；但**单靠它判背驰『很难准确』**（`L25:235-236`）。背驰的定义基础是力度（均线吻面积 → MACD 面积，见 `背驰.md`），**成交量不在定义里**。
- **明确无关**：MACD（`L32:159`『MACD 是 MACD，和成交量没什么关系』）。
- **作部件**：**缺口**（由『没有成交』定义，`L77:9-11`）；**中枢级别**（庄股成交次数，`L20:20-21`，见 `中枢.md`）。
- **作递归起点（可替换项）**：分型不是必然的，**可以用成交量给出递归开始部分**（`L84:62-63`，已收在 `级别.md` §一）：

> 「的递归性定义中给出其最开始的部分，完全可以用别的定义去取代。例如，我们可以用收盘的价位去定义顶分型、低分型结构，也可以用成交↵量给出相应的递归开始部分，只要能保证分解的唯一性，就可以。」

- **作选股经验**：放量突破上市首日最高价 / 放量突破年线后缩量回调年线（`L7:30-31`）；250 天线及周线成交量压力线（`L8:33`）；放量突破回调时买（`L10:57`（答疑））；上市第一天高价不放量突破看都不用看（`L19:50`）；年线附近有新资金进入、从成交量不难发现（`L65:68`）。
- **跨组 / 相邻概念**：**换手率**归本节 §二（作者否定）；**复权／除权**是另一件事（数据口径），已登记为 README 第四节 **#11**（`L10:47`（答疑）·`L23:163`·`L28:54`·`L15:125`），**不在本文件范围**——成交量压力线（`L8:33`）这类价位指标会受复权口径影响，但复权本身别在成交量这张卡上重新发明。
- **跨组**：缺口归动力学组；中枢级别归中枢走势组；递归起点归结构组。

## 五、怎么算

| 项 | 形式 | 出处 |
|---|---|---|
| **成交量的唯一『定义』**（化约式） | 在一个最低的时间段内按该价格重复成交了成交数量个交易单位 | `L30:5` |
| **缺口** | 相邻 K 线间没有成交的区间；回补＝该区间重新出现成交 | `L77:9-11` |
| **背驰辅助** | ①成交量 或 ② MACD 绿柱与后面红柱绝对值大小比较 | `L56:101` |
| **放量骗线警戒** | 缠绕前量不能过大；量突然放大又萎缩过快→骗线几率大增 | `L12:28-29` |
| **选股经验（定性）** | 放量突破上市首日最高价／放量突破年线后缩量回调年线／250 天线及周线成交量压力线／上市首日高价不放量突破看都不用看 | `L7:30-31`·`L8:33`·`L19:50` |
| **短线节奏** | 成交量萎缩买、急剧放大卖 | `L22:135` |

★★ **全部是定性描述，原文没有任何一个量化阈值**——『放量』『缩量』『突然放大』『萎缩过快』『压力线』**一个数都没给**。⇒ 凡写成『成交量突破 N 倍』『换手率大于 N%』之类，都是**我们补的**，不是原文。

## 六、跟引擎有没有关系

★ **程序现在完全不用成交量。**（只陈述，不改程序。）

- **数据没有成交量字段**：`data/*.json` 每根 K 线只有 `t / o / h / l / c`（时间、开、高、低、收）五个键，**没有 volume / amount**。实测 `data/zec_4h.json` 等：`list(d[0].keys()) == ['t','o','h','l','c']`。
- **代码没有成交量**：`core/` `cards/` `tools/` `config.py` `render/` 全仓 grep `成交量|volume|amount|换手|turnover`（大小写不敏感）**0 命中**。
- ⇒ 引擎从输入到输出的整条链（K 线标准化 → 分型 → 笔 → 线段 → 中枢 → 买卖点）**没有一环读成交量**。这是『现状陈述』，不代表『应该或不应该用』——后者是产品决定，不在本卡。
