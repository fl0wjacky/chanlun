## 一、是什么

★ **先看这一条：原文从没有给过「背驰」的单句正式定义。** 唯一近似定义在 `L15:37-40`，而且它**不是直接定义背驰，是先定义『趋势力度』，再用力度比较反过来说背驰**：

> 「如何判断“背驰”？↵首先定义一个概念，称为缠中说禅趋势力度：↵前一“吻”的结束与后一“吻”的开始，期间由短期均线与长期均线相交所形成的面积。在前后两个同向趋势中，当缠中说禅趋势力度比↵上一次缠中说禅趋势力度要弱，就形成“背驰”。」

作者自己给这个定义降过级（`L29:200`）：

> 「这只能算是一个粗糙的定义，一般用 MACD 来辅助判断就可以。精确的背驰定义已经相关证明，必须用到测度论里的很多知识，一般人只」

⇒ 精确的背驰定义「必须用到测度论」（`L29:173`），**原文未给**。所以本概念是**定义有缺口、判据靠辅助工具**的一族。

**术语首见只是一句顺口话**（`L7:45`，讲的是抛股票的火候，不是定义）：

> 「②另一种是第一波就火爆上涨，调整后第二波的上涨，一旦出现背驰或放巨量的，一定要小心，找机会走人。」

| 名字 | 是什么 | 出处 |
|---|---|---|

## 三、特殊情况

- **背驰段可以延续，也可以失效**；「背驰」之于「背驰段」是**成功与未成功**的关系（`L65:85-86`，见上）。
- **进入背驰段后不一定演化成背驰**——小级别的延伸足以让大级别摆脱背驰（`L43:25-26`，见上）。
- **级别关系只有两支，没有第三种**（`L43:20-32`，原文自称「明确分类」）：背驰级别**等于**当下走势级别；或**小于**。第 44 课只补了**必要条件**，充分条件原文说没有。
- **小转大**：小级别转折引发大级别转折（展开概念有定理 `L44:11-14`；「小转大」这个缩略语首见落在**读者提问**里）。
- **区间套**（`L27:57-59`，原文**未给定义**，只给了程序定理）：

  > 「推而广之，可以证明缠中说禅精确大转折点寻找程序定理：某大级别的转折点，可以通过不同级别背驰段的逐级收缩范围而确定。↵换言之，某大级别的转折点，先找到其背驰段，然后在次级别图里，找出相应背驰段在次级别里的背驰段，将该过程反复进行下去，直到↵最低级别，相应的转折点就在该级别背驰段确定的范围内。如果这个最低级别是可以达到每笔成交的，理论上，大级别的转折点，可以精确到」

- **类背驰是另一个东西**：`L65:112` 明写「这和背驰是两回事情」；它的定位在**动力学**，用到它的场合是线段之下的精确买卖点定位。

## 五、怎么算

| 算法 | 形式 | 出处 |
|---|---|---|
| **定义式** | 前后两个同向趋势中，第二个『趋势力度』比第一个弱 ⇒ 背驰；『趋势力度』＝两个「吻」之间两均线相交围成的**面积** | `L15:38-40` |
| **平均力度**（可即时判断） | 当下价格走势与前一「吻」结束时，两均线围成的面积**除以时间** | `L15:45-46` |
| **辅助工具** | MACD（面积／黄白线／红绿柱子）；柱子一波的**山顶**就是转折处 | `L24:2`·`L15:214` |
| **判『是不是背驰』的入口** | 先看**有没有创新高／新低**——没有就按中枢震荡看 | `L44:52-53` |
| **精确定位** | 区间套：大级别背驰段 → 次级别里的背驰段 → 反复到最低级别 | `L27:57-59` |
| **卖点一侧** | 一律「反过来」 | `L101:6` |
| **★ 用 MACD 判断背驰的前提** | ①两段**同向趋势**；②中间由**盘整或反向趋势**连接 —— 三段记作 **A、B、C**；③**B 的中枢级别比 A、C 里的都大**（否则 A、B、C 连成一个大的趋势或大的中枢）；④**A 之前已有一个和 B 同级或更大的中枢**，且那不是和 A 逆向的趋势 | `L53:89-94`（干净重述）· `L24:20-24`（首述，**源站叠字**） |

★ **上表那条『辅助工具』是有前提的 —— 前提不成立，MACD 上那点面积差就不叫背驰。** 作者在第 53 课把第 24 课那段**原话重述**了一遍（`L53:89-94`，**要引就引这版**）：

> 「“用 MACD 判断背驰，首先要有两段同向的趋势。同向趋势之间一定有一个盘整或反向趋势连接，把这三段分别称为 A、B、C 段。显然，↵B 的中枢级别比 A、C 里的中枢级别都要大，否则 A、B、C 就连成一个大的趋势或大的中枢了。A 段之前，一定是和 B 同级别或更大级别的一↵个中枢，而且不可能是一个和 A 逆向的趋势，否则这三段就会在一个大的中枢里了。归纳上述，用 MACD 判断背驰的前提是，A、B、C 段在↵一个大的趋势里，其中 A 之前已经有一个中枢，而 B 是这个大趋势的另一个中枢，这个中枢一般会把 MACD 的黄白线(也就是 DIFF 和 DEA)回↵拉到 0 轴附近。而 C 段的走势类型完成时对应的 MACD 柱子面积(向上的看红柱子，向下看绿柱子)比 A 段对应的面积要小，这时候就构成标准↵的背驰。”」

『』：这条前提的**首述**在 `L24:20-24`，那一版**源站叠字极重**（名词／量词／副词都叠，还有 `D` 这种串进来的字符）⇒ **要引 `L24` 就必须逐字照录、不许顺手改**；要一段能干净引用的，用上面 `L53` 这版。归类上：这条**不是算法，是前提** —— 前提不成立时，面积比较没有意义。

## 六、两种可选看法的口径（card-84091d2d-c97，小栋 2026-10-04 定 B：可切换、默认不变）

『这一节只写**口径**：每一条分三栏 —— 原文说了什么 / 原文没说什么 / 没说的那部分由谁定。代码等口径定了再动。』

### 0. 公共的地方（两种看法都一样，不动）

『**两种看法替换的只是「力度比较」这一步**，也就是 `signals.beichi()` 里『C 段力度 < A 段力度 × 比例』那一行。其余**全部照旧**：A/B/C 怎么取、要创新低／新高才谈背驰（`L44:52-53`）、前提③④（`L53:89-94`）、0 轴回抽（可选）、回拉确认。』
『**作用范围**：跟现有的 MACD 面积一样，信号算在哪一层就在哪一层用（线段层默认，类中枢层对照）。原文没有给『只在某些周期、某些层有效』这类限制，所以**不加限制**。这一句是 Iris 问的界，字面照这个用。』
『**比较的两段**：一律是 A 段对 C 段，窗口取该段自己的 K 线下标范围 `[i0, i1]`，跟 `strength()` 现在取面积用的是同一个窗口。』

### 1. 黄白线不创新高／新低

**原文**：

> 「第三段跌破第一段的 3.2 元，但 MACD 明显出现标准的背驰形态：回抽 0 轴的黄白线再次下跌不创新低，而且柱子的面积是明显小於第 1↵段的，一般来说，只要其中一个符合就可以是一个背驰的信号，两个都满足就更标准了。从季度图就可以看出，万科跌破 3.2 元就发出背驰的信」

> 「缠中说禅：理解错误。柱子出现今天比昨天短，昨天比前天长的情况，证明柱子的一波出现转折，转折这一天的高度如果比上一波转折高度低，↵就形成柱子上的背驰。对于 MACD，单纯看柱子上的背驰还不行，还要看黄线 DEA 和白线 DIFF 的走势，特别对于通道式，一定要看。这个问题以后说技术指标时再说。」

> 「黄白线回到 0 轴附近再上去，股价新高而两线以及柱子都不新高，这时候出现的背离最有效。」

**原文给了的**：
- 「黄白线」＝两条线，黄线 DEA、白线 DIFF（`L15:178`）。
- 比的是**第三段对第一段**（`L27:41` 开头是「第三段跌破第一段的 3.2 元」，后面又说柱子面积「明显小於第 1」段），也就是我们的 C 对 A。
- 「两线以及柱子都不新高」（`L15:208`）⇒ **两条线都要**不创新高／新低。
- 跟柱子面积的关系：「只要其中一个符合就可以是一个背驰的信号，两个都满足就更标准了」（`L27:42`）。

**原文没给的**：
1. 「不创新低」比的是**哪两个点** —— 是两段各自的最低值，还是价格创新低那一根 K 线上的值？
2. 窗口：DEA 比 DIFF 慢，C 段里的最低点可能落在 C 段结束**之后**。窗口要不要往后延？
3. 平了算不算「不创新低」。

**口径（提议，@nova-8980 定）**：
- (a) 向下：`min(DIFF[C]) ≥ min(DIFF[A])` **且** `min(DEA[C]) ≥ min(DEA[A])`；向上反过来，用 max 和 `≤`。窗口就是各段自己的 `[i0, i1]`，**不往后延**。
- (b) 平了（相等）**算**不创新低：『创新低』是比原来更低，相等不是。这一条跟面积的严格 `<` 方向不一样，是因为两边原文的字面不一样，**不是**疏忽。
- 理由：「两线以及柱子都不新高」是对整段说的，取段内极值最直接；窗口跟面积用同一个，两种看法才是在同一段走势上比。

### 2. 柱子一波的峰值

**原文**：

> 「信号。↵再问：“而前面最后位置超不过，才是危险信号。”请问这里所说的“前面最后位置”是上一日的红柱还是上一波最长的红柱？请明示。↵缠中说禅：这个问题很简单的，背驰如果用 MACD 红绿柱子来看，当然是看一波的。红绿柱子的一波怎样构成：就是先伸长，再缩短，而最长↵的位置就是转折点。如果今天还比昨天长，证明转折点还没出来，只有出现今天比昨天短，昨天比前天长的情况，才会出现转折。这个问题一看」

> 「缠中说禅：理解错误。柱子出现今天比昨天短，昨天比前天长的情况，证明柱子的一波出现转折，转折这一天的高度如果比上一波转折高度低，↵就形成柱子上的背驰。对于 MACD，单纯看柱子上的背驰还不行，还要看黄线 DEA 和白线 DIFF 的走势，特别对于通道式，一定要看。这个问题以后说技术指标时再说。」

> 「MACD 关键是处理好红绿柱子的一波，与一波中的高点转折的关系。每个红绿柱的一波都像一个小山，山顶就是转折的地方，这一看图就↵明白了。」

**原文给了的**：
- 一波＝「先伸长，再缩短」，最长那根是转折（`L15:172`）。转折的判法是「今天比昨天短，昨天比前天长」（`L15:173`、`L15:177`）。
- 背驰＝「转折这一天的高度如果比上一波转折高度低」（`L15:177-178`）。
- 一波「像一个小山，山顶就是转折的地方」（`L15:214`）。

**原文没给的**：
1. **「一波」怎么切**。照「今天比昨天短，昨天比前天长」逐字切，一段同色柱子里常常有好几个山顶。实测：同色段里有两个以上山顶的，btc_4h 132 段里有 81 段（61%）、zec_1h 300 段里有 181 段（60%）、zec15 1346 段里有 820 段（61%）、aaplusdt_1h 92 段里有 66 段（72%）。也就是说，『一波＝一段同色柱子』和『一波＝一个山』这两种切法，结果差得很远。
2. 「上一波」放到 A/B/C 框架里对应什么。`L15` 那几段是问答，讲的是相邻两波，**不是** A 段对 C 段。

**口径（提议，@nova-8980 定）**：
- (a) 比 **A 段里最高的山顶**和 **C 段里最高的山顶**（只看与该段同向的颜色）。C 的低于 A 的 ⇒ 背驰。
- (b) 这样定有一个好处：**段内最高山顶＝段内同向柱子的最大绝对值，不管「一波」怎么切，结果都一样**。上面那个切法上的分歧（60% 多峰）就不会影响结论，不用我们替原文发明切法。
- (c) **没采用**的读法，记在这里：照 `L15` 字面拿『C 段最后一波』对『它前一波』比。这个读法离 A/B/C 框架太远，而且结果取决于切法。要用它，得先另定切法，这一步原文没给。
- (d) 平了**不算**背驰：原文是「转折这一天的高度如果比上一波转折高度低」，相等不是「低」⇒ 用严格 `<`。跟上一条黄白线的 `≥` 方向相反，原因同上：照各自的字面。

### 3. 两种看法和现有面积怎么组合（小栋 2026-10-04 定 ②A：加『面积或黄白线』，card-bead5f56-74b）

**原文**：`L27:42`「一般来说，只要其中一个符合就可以是一个背驰的信号，两个都满足就更标准了」，说的是**黄白线**和**柱子面积**两者的关系。

**原文给了的**：
- 两者**任一**符合就算一个背驰信号（上面那句原文的前半句）⇒ 『或』有原文依据。
- 两者**都**符合「更标准」⇒ 『且』不是另一种判法，而是『或』里面**更强的那一部分**。

**原文没给的**：
1. 「更标准」在操作上意味着什么：多发一个点？换一个价位？还是只是更可信？原文没说。
2. 峰值那一条跟面积、黄白线怎么组合，原文没说。

**口径（小栋 ②A 定『或』；下面几条细节是编者口径，@nova-8980 可改）**：
- (a) 新增第五种看法 **面积或黄白线**（建议代号 `macd_or_lines`）。判背驰 ⇔ **面积那条成立 或 黄白线那条成立**，两条各自**原样**照本节第 0 条与第 1 条的定义：面积是 `C 的面积 < A 的面积 × ratio`（严格 `<`）；黄白线是两条线都不创新低／新高，持平算不创新（六.1 (a)(b)）。**不发明第三种比法**，窗口、ratio、方向都跟单选时一样，ratio 只作用在面积那半边。
- (b) **「更标准」只打标记，不另出点**：两条都成立的点照常发一个，身上多一个标记（建议字段 `std: true`）。理由：原文只说「更标准」，没说要多一个点或换位置。前端要不要显示这个标记，另议。
- (c) 『面积且黄白线』**不单独做成一个选项**：它就是 (b) 里打了标记的那一部分。要单看，按标记筛。
- (d) 峰值**不进组合**：原文没说它跟谁组合（同第 2 条）。
- (e) 默认仍是**面积**。六.0 那些全部照旧：A／B／C 怎么取、要先创新低／新高（`L44:52-53`）、前提③④、回拉确认。『或』只替换力度比较那一步。

**由此推出、可以逐点核的两条**（Bram 实现后我拿它们核）：
- **并集恒等**：同一份数据、同一层、同一个 ratio，『或』发的一类点集合 ＝ 『面积』的 ∪ 『黄白线』的，**逐点相等**（kind、bar 都对上）。理由：三者只有力度那一步不同，前面的门、后面的回拉都一样。这条不成立，就说明『或』偷偷改了别处。
- **标记恒等**：打了 `std` 的点 ＝ 『面积』∩『黄白线』，也是逐点相等。

**另记一句（小栋 2026-10-04 定 ①A，card-6381042d-03f）**：**斜率**（价差÷根数）**不是原文给的判法**，是我们早期自己加的。保留，但页面上标『非原文』，`/api/meta` 的 `measure_orig` 里是 `false`。原文里『斜率』这个词出现过一次，是在讲类背驰时顺口说的：「如果不能继续保持类似斜率的上涨，那么这线段类上涨结束形成一个 1 分钟中枢就要情理之中了。」（`L98:17`），没有定义成一种比法。所以『非原文』指的是这种比法，不是这个词。

### 4. 交付时要列的数

每种看法在 9 份数据上各出多少个一类点、跟默认（面积）的交集多少；默认配置下 selfcheck、parity、pine_lockstep 逐位不变。两种新看法**各要一个探针能变红**：把黄白线的比较方向反过来，或者把峰值换成均值，都必须红。

**『面积或黄白线』那一种另加**（card-bead5f56-74b）：
- 9 份数据上各出多少个一类点，跟『面积』『黄白线』各自的交集；上面两条恒等式（并集、标记）逐份列出『成立／不成立』。
- 默认（面积）配置下 selfcheck、parity、pine_lockstep **逐位不变**。
- 探针要能变红：① 把『或』换成『且』⇒ 并集恒等式必须红；② 把黄白线那半边摘掉 ⇒ 并集恒等式必须红。这一条只在『黄白线独有的点』不为 0 的数据上才有牙，**为 0 的数据要明写『这份上空转』**，不许算作绿。

## 七、两条实现纪律（编者口径，开源对照第二页定 B，card-b4e8695f-4ca）

这两条**不是原文**，是对照 YuYuKunKun/chanlun.py（2e4fa13）时量出来的两个坑。写在这里，是防我们以后加新看法时掉进去。证据和复跑脚本在卡上那一页。

### 1. 力度量法的量纲要统一

**纪律**：拿来比力度的那个数，只许由**同一种量纲**的东西组成，或者是原文给的那种比值。原文的平均力度就是面积比时间（『均线形成的面积除以时间。』，`L15:46`），是一个比值，不是把面积和时间直接相加。
**反例**：那家的『测度背驰』把**秒**（时间戳之差）和**价格**开平方后相加。秒的数量级比价格大几个量级，结果这一票就等于『只比时长』。在 3 份真数据、152 对线段上，它跟『只比时长』的判法 **152/152 相同**。
**我们现在**：面积（MACD 柱求和）、斜率（价差 ÷ 根数，`core/signals.py` 的 `strength`）、黄白线、峰值，都不混量纲。**以后加新看法时，先过这一条。**

### 2. 指标的中间状态不许取整后带进下一根

**纪律**：EMA、DEA 这类**递推**算出来的量，存进状态、拿去算下一根时一律用**全精度**。要取整，只能在**显示**那一步。
**反例**：那家把快线 EMA、慢线 EMA、DEA 都 `round(…, 2)` 后存起来，下一根接着算。同一份 ZEC 15m 走势：真价位（193–1684）20160 根里只有 72 根柱子正负反了；**缩到 ×0.001**（0.19–1.68，模拟低价币，明说是缩放的）就有 **10511 根反号**，误差是柱子幅度的 211%。面积、峰值这类看法拿反号的柱子来算，结果没有意义。
**我们现在**：`core/signals.py` 的 `macd_lines` 全程不取整（grep 过，那一段没有 `round`）；后台 `/api/macd` 回的也是这一份。**以后谁要在那里加取整，这一条就是不许的理由。**
