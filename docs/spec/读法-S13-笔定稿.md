## 一、原文怎么说『一笔完成』

- **L77:37-40（正文）**：笔＝一顶一底，顶底之间至少一根 K 线不属于两个分型；顶分型最高那根要有一部分高于底分型最低那根。按这些条件，笔的划分唯一。
- **L77:41-53（正文，唯一性证明）**里给了『没完成』和『定下来』的判据：
  - 一个底不经过一个顶就出现更低的底 ⇒ 那一笔**没完成**（:47-48）。
  - 下一个顶分型出现之前，没有底分型低于前面那个底 ⇒ 那个顶必然高于这个底，**前面的底和这个顶就是新的第 N+1 笔，第 N 笔从此唯一确定**（:51-52）。
- **L91:15-45（正文，笔定理）**：任何当下都落在一笔里，状态只有两种：分型构造中、分型确认后延伸为笔的过程中；状态之间的连接是有限的（向上笔延伸中只能接向上笔的顶分型构造中，等等）。
- ⇒ **原文的『笔定稿』判据（拟作 P1）**：第 N 笔（比如终点是底 B）在**第 N+1 笔成立**的那一刻定下来 —— 也就是 B 之后出现一个顶分型，跟 B 隔够（B-1 的根数档）、满足 L77:38 的高低条件，而且在它出现之前没有比 B 更低的底分型。L77 的证明保证：此后不论怎么走，第 N 笔都不会再变。

## 二、引擎为什么会改到倒数第 20 笔

- 引擎在 L77 之外多了两道**回头修正**（core/pen.py 文件头『划法』）：
  1. 笔的两端必须是这一笔的最高最低（依据：答疑 L66／L70／L71 同一句话，『如果不是，那里面一定不只一笔』）；
  2. 『待定』分型：挨得太近、却比前前个端点更极端的反类分型先记下，之后上一端点被替换时回头作废上一笔、改端点；替换后仍有端点不是极值 ⇒ **再往回找更早的同类端点**合成一笔。
- 第 2 道的『再往回找』没有上限 —— 这就是尾笔改写最远够到倒数第 20 笔的来源（我的推断，**请 Bram 用那 12 次撤销核：每一次是哪一道修正改的**）。
- ⇒ **这里有一个读法冲突（要单列）**：按 L77:51-52（正文），第 N+1 笔一成立，第 N 笔就定了；而引擎为了守住『端点必为极值』（答疑层）会回头改已经按 L77 定下来的笔。正文效力高于答疑。

- **量了（Bram 06:22，25 张，按笔取 K 线前缀）**：笔序列改动 5349 次，从倒数第 1 笔起改 4847、第 2 笔 411、**第 3 笔及更早 91 次**（最深到第 20 笔 1 次）。照 P1 的保守读法（最后两笔不定稿），这 91 次（1.7%）就是『定稿后改写』⇒ **P2 违反 >0，推断成立**。
  - **更正（Bram 06:25 看代码）**：引擎笔列表里的最后一笔**一定已经成立**（端点分型右边已有 K 线确认、隔够、两头是极值才进列表；L91 说的『分型构造中』对应的是末端点后面还没成笔的那一截，不在列表里）。⇒ 按 L77 严读，倒数第 2 笔每一刻都已定稿，那 411 次**全部**算定稿后改写：**P2 违反下限 502／5349（9.4%）**（仍是下限，取样间隔里的改动会叠成一次）。下面这条原话留痕：

- **502 次定稿后改写按引擎的路分（Bram 06:56）**：『作废上一笔』（pend 待定分型）414（深度 2 的 411 全在这）；fix_start『P 当端点』43；fix_start『合并』45（深的 88/91 在这两条）。⇒ P2 落地要**三条路都拦住碰定稿笔的那一下**：只关 fix_start 还剩 414，只关『作废上一笔』还剩 88。拦了以后非极值端点多几处，待量。

- **P2 开关 `PEN_FINAL_LOCK`（Bram 07:27，6155824，默认关时 25 张输出 sha256 不变）**：小样 data/aaplusdt_30m 锁上以后，定稿后改写 22→0、线段确认后撤 1→0，**非极值端点 0→27**（P3 的代价），线段确认延迟中位 313→286 根。全量 25 张在跑。
  - 这 27 处只违反答疑里『端点必为这一笔最高最低』那一句（L66/L70/L71）；L77 正文的成笔条件（顶底隔够、顶高于底）照旧满足，这一点请 Bram 全量时一并核（锁下是否出现违反 L77:37-40 的笔，期望 0）。

  - **我的读法：这不是 P2 跟正文冲突，是 P1 我写得不严。** L77:51-52 说的是『第 N+1 笔**成立**，第 N 笔就定了』。末笔终点一延伸、它不再满足 L77:37-40，第 N+1 笔就**不成立了**，P1 的前提跟着失效，第 N 笔回到未定稿，改它不违反 P2。⇒ P1 改成『第 N+1 笔成立**并且一直成立**时，第 N 笔定稿』。落到代码就是 Bram 说的 (a)：只有在『延伸会让末笔违反 L77 正文成笔条件』时，才许动倒数第二个端点。这不是例外，是 P1 本来的意思。
