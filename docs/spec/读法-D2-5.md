# 读法 D2-5：盘整背驰的 A 段怎么取（为什么六成刀标『比不了』）

> **来由**：Nova 10-09 06:41。现行（非同级别）96 刀里 D2 那类 92 把、『比不了』59（64%）；同级别 S9＋甲同样六成左右（Bram 06:15）。分类：进入段跟 C 反向 29、找不到 Z 19、找不到 A 3 —— **这组是乙′ 口径**（Bram 06:14；S9 底座下『进入段反向』是 37）；正式口径 S9＋甲下的基数还没单独数，量的时候先报。要 Atlas 读原文、写条款草稿。只写文档，只给课号行号指针和转述。

## 结论

**原文对盘整背驰的 A 段给了两种取法，现行只用了其中一种。** 现行（10-08 改）只取『进入中枢 Z 的那一条』（L24 的 A、B、C 结构）；进入段跟 C 反向时就标比不了。可原文另有三处（两处正文、一处答疑）明说可以拿**中枢里跟 C 同向、隔一段的那一条**比（L39 的 Ai 对 Ai+2、L27 的第一段对第三段、L37 答疑 a 对 c）。补上这第二种取法，『进入段反向』那 29 刀大多能比；『找不到 Z』那 19 刀里，C 前三段自己重叠的那部分也能比。

- **为什么 (a) 优先**：10-08 改成 (a) 的时候，是 Bram 量出原写法（『最近一次离开同一中枢的同向段』）91 刀里 85 刀找不到 A；(a) 是原文里讲得最完整的结构（L24），而且它比的是『这一中枢前后两次同向推动』，最接近背驰本义。(b) 是补位：原文明说可以，但它比的是中枢内部的两次波动。**Nova 10-09 06:43 定：(a) 优先、(b) 补位（-1→-2→-3→-4），编者口径**；现有能判的刀一刀不动。
- **跟 R-1 的关系**：同级别下（已选），L39 正文那条 Ai 对 Ai+2 正是同级别分解的原话，(b) 的依据在同级别下更硬。
