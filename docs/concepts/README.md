## 五、口径（三组共用）

- 原句照语料文件原样抄，不修抓取重字；删重字也还原不了原义的标 [残]，不猜原文。
- 「首见」只写课号；日期只抄被引那一行或源页标题上印着的，不推。
- 出处核对：回被引那一课找；回全书找只用来查复述，不算出处核验。两个数分开报。
- 凡要写成「唯一／首见／全书只有 N 处」的数，必须在折行合并后的文本上数，不手写。
- 跨课命中有两种形状：相邻课整段复述、定理被后文反复引用。各附例子，不下结论。
