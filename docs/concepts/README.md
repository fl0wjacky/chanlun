5. **少数能直接变成算法的定义**：

## 六、口径（三组共用）

- 原句照语料文件原样抄，不修抓取重字；删重字也还原不了原义的标 [残]，不猜原文。
- 「首见」只写课号；日期只抄被引那一行或源页标题上印着的，不推。
- 出处核对：回被引那一课找；回全书找只用来查复述，不算出处核验。两个数分开报。
- 凡要写成『唯一／首见／全书只有 N 处』的数，必须在折行合并后的文本上数，不手写。
- 跨课命中有两种形状：相邻课整段复述、定理被后文反复引用。各附例子，不下结论。
- `docs/术语别名表.md` 已于 `58bf5c79` 按删换行重算；表头写明了哪些数是手算未重算的。
- 「首见」分两栏：**说法首见**（词第一次出现，可能只是预告）和**内容首见**（真正给出内容）。例：「两个前提」说法首见 L29:214，内容首见 L30。只有预告没有兑现的，内容首见写『原文未给』。各组以附录补丁表落，不改正文列。
- 引原文：当证据或定义用的整句，至少引到句号或分号；中途截断必须打「……」。术语、短语不受这条限制。截引不做机器统计，靠读的人自己核。
- 检索盲区三类，都不报错：① 没去找；② 找到了但只截了自己要的半句；③ 族词表里根本没有这个词（尺不认字，报一个假的 0）。族词一律由清单反推、脚本生成。
- 报『0 条不中』必须同时贴阳性对照（故意造一句，看它报错）和阴性对照（贴一句真原句，看它通过）。
- 凡报出的数，必须能用仓库里的脚本复算，报数时写出命令和 ref；脚本不在仓库的数一律作废。
- 同一份文件在两把尺下读数不同（例：动力学那把尺剥反引号、统一尺不剥，一边 0 一边 3）⇒ 以统一尺 `notes/concepts-pipeline/checkquotes.py` 为准；『我这边绿』不等于可交付。

- 新增的原文定义（读完阶段找到的）：底部＝第一类买点出现后，到该买点引发的中枢第一次走出第三类买卖点前；三卖先出＝构造失败，三买＝构造完成（L108:3-6）。
