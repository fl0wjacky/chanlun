- ★★ `L56:113`–`116` **（清单已引 `L56:117-118`，补前因）**：C 段高点**没有**重回 B 段内部最后一个反弹的启始位置 —— 这**并不违反理论**，因为 B 段内部最后一段向下**并没有背驰**，它的转折**完全是小级别转大级别造成的**。⇒ 清单引的那句是结论，`L56:113`–`116` 是它唯一的实证。
- ★★ `L56:63`–`64` **底部要看下级买点**：「这 30 分钟的顶背驰压力，怎么都需要一个至少 1 分钟的底背驰才能有比较有力度的反弹…**真正的底部构筑，必须让这些级别的图形重新走出买点来**。」

#### 第 33 课《走势的多义性》——三种多义性＋背驰的中枢释义（特异词 37，课长 195 行／脚本口径）

**清单里已有的**（2 处）：`L33:64`／`L33:64-66`（顶背驰的中枢定义）· `L33:88-89`（MACD 判别的方向性）。

**本批新增，拟补**：

- ★★★ `L33:52`–`67` **背驰的『中枢释义』——一个与「力度」平行的定义路径**：站在 B 中枢的角度，`b` 是**向下离开**中枢 B、`c` 是**向上离开**中枢 B；「**所谓顶背驰，就是最后这个中枢，向上离开比向下离开要弱**」，理由是「中枢对无论向上或向下离开的，都有**相同的回拉作用**」——向下离开都能拉回中枢，那更弱的向上离开当然也能拉回。⇒ 清单的「背驰」条现在只有**力度释义**（`L15:37-40`），本课给出**第二条独立路径**，且这条**不依赖均线面积、不依赖 MACD**。
- ★★★ `L33:67` **盘整背驰与背驰的本质统一**：「其实，站在中枢的角度，**盘整背驰与背驰，本质上是一样的**，只是力度、级别以及**发生的中枢位置**不同而已。」⇒ 与 `L53:27-28`（清单已收：「盘整背驰，只是利用前者(背驰)相应的力度分析方法进行的一个推广用法」）是**同一条的两次出现**，本课更抽象。★ 两者的差落在**中枢位置**上，恰与 `L21:33-35`（三类买卖点相对最靠近的中枢）接得上。
- ★★★ `L33:88`–`89` **（清单已引，逐行读后要补后半句）**：「如果用 MACD 来辅助判别，背驰比较的黄白线和柱子面积**都在 0 轴的一个方向上**…而 a+A+b 与 c 就**分别在不同的方向上**，由於这，也不存在黄白线回拉的问题，**但有一点是肯定的：黄白线至少要穿越一次 0 轴**。」⇒ 清单只引到「不存在黄白线回拉的问题」，**把『必须穿越 0 轴』这句落下了**，而那才是可用的判据。这是本批第二处“引到一半”。
- ★★★ `L33:9`–`10` **中枢延伸的数量上限——一条硬规则**：「一般来说，**中枢的延伸不能超过 5 段**，也就是一旦出现 **6 段的延伸**，加上形成中枢本身那三段，就**构成更大级别的中枢**了。」＋ 附录 `L33:159`–`162` 追问『盘整+盘整还是盘整，那不就还是 5 分钟中枢吗』，答：「盘整+盘整还是盘整，但**加多了就是级别大的盘整**，这没有什么问题。**盘整还有一个级别的问题。**」⇒ 这是**级别如何“长大”**的可数规则，清单的「中枢延伸」条只有定性描述。★ 与第 56 课 `L33:93-95`（段归属判错就数错中枢）配套使用。
- ★★★ `L33:106`–`109` **围绕中枢的操作总纲（全文最凝练的操作段）**：「每次**向下离开中枢只要出现底背驰**，那就可以介入了，然后看相应回拉出现**顶背驰的位置是否能超越前面一个向上离开的顶背驰高点**，不行一定要走，行也可以走；但**次级别回抽一旦不重新回到中枢里，就意味着第三类买点出现了，就一定要买回来**。而如果**从底背驰开始的次级别回拉不能重新回到中枢里，那就意味着第三类卖点出现，必须走**，然后等待下面去形成新的中枢来重复类似过程。」
- ★★★ `L33:68`–`87` **B 级别大于 A 时可以直接反向**：`a+A+b+B` 中 B 级别大于 A 时，「**并不必然地 B 后面就接着原方向继续，而是可以进行反方向的运行**」；`L33:84`–`87` 反转是否成功的判据＝**比较 `a+A+b` 与 `c` 两段的力度**（中枢 B 对两者的回拉力度一样），c 更弱则「一定要重新回到中枢里，**在最强的情况下也至少有一次回拉去确认能否构成一个第三类买点**」。★ `L33:86`–`87` 这句把『反转失败』与「三买」扣在一起，是清单里没有的接口。
- ★★ `L33:96`–`100` **c 反转成功的直观判据＝必须回到 b 的起跌点**：「在相同级别内至少要表现出比 b 的力度不能小…也可以从一个最直观的位置来分析，就是**必须能重新回来 b 的起跌点**，这就如同向天上抛球，力度大的如果还抛不高，那怎么能算力度大？」＋「至于 c 能不能回到 b 的起跌点，**那可以分析 c 内部的小级别，如果 c 出现顶背驰时还达不到该位置，那自然达不到了，所以这种分析都是当下的，不需要预测什么**」。⇒ 『当下、不预测』在这里有一次**可操作化**的落地。
- ★★ `L33:147`–`149` 「次级别**不跌回中枢里面**就是第三类买点，**但能不跌回最高点那自然是最强的**」⇒ 与 `L29:202-205`（三买在第一个中枢后效果最好）互补：一个是**位置**效应、一个是**强度**效应。
- ★★ `L33:150`–`153` **中枢扩张只针对一个中枢**：「什么叫两个同级中枢扩张？**中枢扩张只针对一个中枢说的**，从原来的什么级别到什么级别，哪里来两个的问题？」⇒ 清单「中枢扩张」条缺这句边界；★ 与 `L56:147-148` 的实算（1 分钟→5 分钟）互相印证。
- ★★ `L33:155`–`158` **B 什么时候“继续发挥作用”**：只要 c 最后**没有形成和 B 同级别的中枢**（准确说：**至少是同级别且不重叠的**，比它大的也可以），B 这个“星球”就继续起作用；「原来的不是没作用，而是**归入一个大的中枢系统里**发挥作用了」。
- ★★★ `L33:191`–`194` **MACD 三要素的优先次序（一条被直接问出来的回答）**：（问）「用 MACD 辅助判断顶背驰，是否存在**红柱子长度、红柱子面积、黄白线**判断的优先次序？」（答）「一般来说，**最重要的是黄白线，柱子面积之和一般在复杂走势里重要**。但其实这都不是最关键的，**最关键是要各级别配套地看**，才能知道哪个背驰的力度大；否则，每一个 1 分钟以下的背驰都要动，那就会累死。」＋ `L33:193`–`194`「但如果中枢就是 5、30 分钟的，每次离开都是 1 分钟的，那 **1 分钟以下的背驰当然就很重要**，因为根据中枢的回拉力，1 分钟以下背驰就引发大的回拉。」
- ★★ `L33:119`–`120` **某级别的背驰「至少结束该级别的走势」**，且（问『盘整背驰是不是由次级别趋势背驰造成的』）答：「**不一定就是**某级别的盘整背驰是由次级别的趋势背驰（造成的），否则研究 a`+B 这些就没意义了。」⇒ 清单「盘整背驰」与「背驰」的**从属关系**在这里有一条否定的边界。
- ★★ `L33:145`–`146` **递归式的第二次出现（清单 0 次）**：「**递归，最小级别的中枢用三根 K 线就完了。然后用类似 an+1=f(an) 的形式进行下去就可以。**至于盘整、趋势这些概念，其实没有也可以的，只是将就大家的习惯，**唯一有效的就是中枢的概念，其他都是多余的。**」⇒ 与 `L29:156-157`（第 4 批已收）是同一条的两次出现，且本课**给出了最低级别的具体答案**（三根 K 线）；★ 全库该式还有第三次：`L37:55`（用在『分段函数各段定义互不相关』的类比上）。⇒ 递归式**全库 3 课**，我第 4 批说“给中枢递归一个数学底座”时只引了 1 课，现更正为 3 课。
- ★★ `L33:184`–`185` **力度与级别的一般关系**：（问「是否背驰越大越有力度？是否级别越大越有力度？」）答：「**一般情况下是这样**，但**如果转化为 a`+B 的情况，往往最小级别的也不能轻视**，有些走势的能量是**逐步积累**而来的。」⇒ 与 `L31:281-282` 的门槛（至少 5 分钟进背驰段才有效）**方向相反但可以并存**：门槛说的是常态，这里说的是**例外**（a`+B 型）。
- ★ `L33:171` **量是辅助**：「**量当然有意义，但更多是辅助的，图形的结构才是第一位的。**」；`L33:174`「跌，只能考虑买；涨，只能考虑卖。」；`L33:102`–`103`「有了这么精确分析，**所有的均线其实都没什么意义了**」；`L33:112`–`113` **指数与个股要分开**（个股只要指数不单边下跌就活跃，不能完全按指数来弄）。

#### ★ 本批关于语料的一条：**第五种形态——批注者的话混在正文里（「匪注」）**

第 33 课 `L33:52`–`53` 那句 **「（匪注：力度就是走势的斜度，以及持续的时间）」** 不是原文作者的话，是**后世批注者（署名“匪”）的夹注被排进了正文**。

- **全库「匪注」共 5 处**：`L14` · `L17` · `L24` · `L32` · `L33`（去折行后数；**单行尺下 `grep '匪注'` 得 0** —— 因为 `L33:52` 行尾是「(匪」、`L33:53` 行首才是「注：」，**折行把这两个字劈开了**。⇒ 又一次『两把尺』，且这次是**同一把刀同时砍出漏检和错误归属**）。
- **要紧的不是噪声，是归属**：清单的「力度」条至今**没有作者给出的定义**——`L15:37-40` 定义的是「缠中说禅**趋势**力度」（吻的面积）。全库唯一一句把“力度”说成人话的**『斜度＋持续时间』是批注者的**。⇒ 正确写法是把这句收进来但**明确标为『批注者语，非原文』**，不能让读者误以为作者定义过力度。这与 `L29:215`「类第一类买点」是**同一类错误**（别人/读者的词被当成作者的词），只是这次错在语料层。
- ⇒ 建议在 §15 的口径说明里把噪声从四种**补成五种**，并把『**异质文本（批注）混入正文**』列进去；凡引到 `匪注`，一律标『批注』二字。

#### 本批三课的共同发现（写进 §15.3 的一句话结论）

第 21／56／33 三课的**特异词并列 37**（本表里同分的还有 20／17 等），但读下来料**完全不均**：
- **21 课**是**体系的家**（完备性定理——分类“全不全”的问题）；**56 课**是**尺的家**（MACD 看什么、怎么合并面积——“怎么量”的问题）；**33 课**是**定义的家**（背驰的中枢释义、多义性——“是什么”的问题）。
- ⇒ 再次印证 `L24` 那条老结论的**推广形式**：**特异词是同分的，料是分型的**——同分数的课可能分别在补『全不全／怎么量／是什么』，**不能按分数排优先级，只能按“清单缺哪一类”排**。本批三课恰好各补一类，这是分数给不出的信息。
