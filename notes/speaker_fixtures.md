# 说话人轴的固件（@iris-64a1 当场取 · 逐字 · 2026-09-30）

> 用途：**任何"省略/失真"判据上马前，先在它们身上跑一遍**。三条是三个不同的洞，
> 一条挡不住另一条 —— 见每条末尾那半句。
> ★ 这些是**固件**不是"示例"：红了才算立住，红了**红成什么样**才算立住（点得出是哪个键、删了几字）。

## 固件① 删字（未标记）· `cards/c06_trend.py:99`（blob `5544fa35`）

```

## 固件② 插字 + **段首删字** · `core/pen.py:201`（blob `3b644272`）

```

## ★★ 回归点（唯一一个"已知真值"）· `core/segment.py:8`

## 两条边界（跟着固件一起钉死，否则下一个人会以为固件①红了就万事大吉）

```
① **量级门**：一个真删字是一两句。第一版没有这道门 ⇒ 报出「删了 335537 字」「450012 字」——
   那不是删字，是两个碎片落在语料两处，在**两个陌生地址之间虚构了一段"被删掉的原文"**，
   还给我们自己的代码定了一个不存在的罪。⇒ 量级不合理 ⇒ 答案不是"很大的一个数"，是**不能定位**。
② **段首/段尾的删字看不见**（固件②）⇒ 固件②必须单列，别指望①能覆盖它。
```

★ 而"换问题"（相邻性）**换完还得定切法**：相邻性这一问之所以能不可寻绿，靠的是
**贪心最长匹配没有自由参数**（没有阈值、没有候选集）—— 换一个还要选切法的问题，绿脸就跟着换回来。
